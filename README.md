# Agenda de Contactos con React, Tailwind CSS y SQLite

Aplicación web para gestionar contactos con React, estilos Tailwind CSS y base de datos SQLite (via sql.js en WebAssembly).

## Características

- CRUD completo de contactos
- Búsqueda por nombre, apellido o teléfono
- Grupos con colores personalizados
- Marcar favoritos
- Envío directo por WhatsApp
- Compartir contactos y descargar .vcf
- Detección de duplicados (Levenshtein)
- Estadísticas con SQL
- Copia de seguridad (exportar/importar .db)
- Historial de mensajes por WhatsApp

## Instalación

```bash
npm install
npm run dev
```

## Tecnologías

- React 18
- Tailwind CSS 3
- sql.js (SQLite en WebAssembly)
- Vite
